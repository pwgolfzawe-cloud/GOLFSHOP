# ร้านรู้ (Ranroo)

ระบบเก็บข้อมูลขาย TikTok + ต้นทุน + บัญชีภาษีบุคคลธรรมดา สำหรับร้านค้าออนไลน์

## ใช้งาน
เปิดที่ GitHub Pages ของ repo นี้ได้เลย (ดูลิงก์ในหัวข้อ **Deployments** หรือ Settings → Pages)

## ฟีเจอร์
- บันทึกการขายหลายสินค้าต่อบิล เห็นกำไรทันที
- คลังสินค้า + เติมสต็อก (ต้นทุนเฉลี่ยถ่วงน้ำหนัก)
- วัสดุแพ็ค (กล่อง/บับเบิ้ล/เทป) ซื้อเป็นล็อตราคาไม่คงที่ได้
- รายจ่าย + บัญชีภาษี (เทียบหักเหมา 60% vs ตามจริง, ภ.ง.ด.90/94, เตือนเพดาน VAT)
- ค้นหา/กรองรายวัน–ช่วงวัน ทุกหน้า
- หลายผู้ใช้/หลายร้าน แยกข้อมูลด้วย Row Level Security

## เทคโนโลยี
- Frontend: HTML/JS ไฟล์เดียว (`index.html`)
- Backend: Supabase (PostgreSQL + Auth + RLS)

> หมายเหตุ: `index.html` มี Supabase URL และ anon key ซึ่งเป็น public key โดยธรรมชาติ ความปลอดภัยของข้อมูลมาจาก Row Level Security ฝั่งฐานข้อมูล ไม่ใช่การซ่อน key
